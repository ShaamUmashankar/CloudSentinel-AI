Four-Domain Architecture Integration

Cloud Engineering

AWS CloudTrail log ingestion architecture, IAM permission evaluation, and simulated containment (Session revocation, DenyAll quarantine, VPC NACL).

  • CloudTrail event mapping
  • Least-privilege IAM guardrails
  • Simulated containment actions
Data Engineering

High-performance Pandas ETL pipeline for cleaning, timestamp standardization, deduplication, and PySpark Glue job blueprints.

  • JSON & CSV log normalizer
  • Batch & DB deduplication
  • ETL summary accounting
Machine Learning

Scikit-learn Isolation Forest anomaly detector extracting 10 security feature dimensions with SHAP-like explainable feature attribution.

  • Continuous anomaly scores
  • Explainable contribution %
  • Configurable alert thresholds
Generative AI (RAG)

Retrieval-Augmented Generation assistant leveraging local FAISS vector search over MITRE ATT&CK and AWS security playbooks.

  • FAISS vector index
  • Gemini API or Fallback mode
  • Evidence-backed citations
